# Adventskalender 2026

Eine neue Wichtelschul-Geschichte mit 24 täglichen Rätseln.

## Start

Die Anwendung liegt direkt in der Repository-Wurzel:

- `index.html` – Kalenderübersicht
- `day1.html` bis `day24.html` – Tagesrätsel
- `qr-codes.html` – druckbare QR-Codes

Die Seiten werden über GitHub Pages veröffentlicht.
